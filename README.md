==================================================

1. CORE CREATIVE DIRECTION

==================================================

Create a premium, editorial, luxury wedding photography website.

The website should feel like a high-end creative studio / fashion editorial brand, NOT like a generic wedding photography template.

Design references in terms of quality and restraint:

- Apple

- Aesop

- Vogue editorial layouts

- Kinfolk

- luxury fashion photography websites

- premium creative studios

- modern architecture portfolios

Do NOT copy any of these websites.

The visual language should be:

- cinematic

- editorial

- elegant

- warm

- emotional

- minimal

- spacious

- sophisticated

- image-first

- premium

- slightly artistic

- modern Kerala luxury

Avoid:

- generic wedding template aesthetics

- excessive gold

- excessive gradients

- cheesy hearts

- wedding rings icons everywhere

- stock-looking layouts

- excessive glassmorphism

- excessive animations

- huge amounts of text

- card-grid-heavy SaaS UI

- bright wedding pink

- childish design

The photography must be the hero of the website.

Use generous whitespace, asymmetrical layouts, oversized typography, editorial cropping, large photography, subtle borders and carefully controlled animation.

13. IMAGE SEO

==================================================

This is extremely important for a photography company.

Before upload, images should use descriptive filenames.

Bad:

IMG_2938.jpg

DSC00182.jpg

Good:

oriana-weddings-calicut-candid-wedding.webp

or:

oriana-wedding-calicut-bride-groom.webp

Do NOT keyword stuff.

Every meaningful image needs accurate ALT text.

Example:

" Candid bride and groom wedding photography in Calicut by Oriana Weddings"

Do not use the same alt text repeatedly.

Implement:

- WebP/AVIF where appropriate

- image compression

- responsive srcset

- width/height

- lazy loading

- optimized hero image

- descriptive filenames

- meaningful alt text

- captions where useful

Do NOT rely on EXIF/GPS metadata as an SEO strategy.
